# Mission

## Purpose

Native PocketBook client for BookOrbit; maintain an upstream-friendly fork with reliable multi-library selection on InkPad 4.

## Goals

- Ship a tested library selector preserving offline reading and downloaded books.

## Boundaries

- Preserve the exact project root selected by the user.
- Prefer existing project conventions over new abstractions.
- Keep durable coordination in the project's task record and the committed rule docs.
- Do not make destructive changes without explicit user approval.
