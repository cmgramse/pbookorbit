# Success Criteria

## Goal Achievement

A task is complete when the requested behavior works, scoped files are updated, the project's task record reflects reality, and verification evidence is recorded.

## Acceptance Checklist

- The change satisfies the user-visible goal.
- The implementation follows local project patterns.
- Relevant tests or manual QA have been run.
- AGENTS.md/CLAUDE.md guidance remains accurate if the workflow changed.
- The project's task record, notes and decisions are current.
- Scratch created during the task has been distilled or deleted (`workspace-hygiene.md`).
- Reviewer findings are resolved or explicitly deferred.
